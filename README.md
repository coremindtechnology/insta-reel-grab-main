# InstaFetch Project

This project has been reorganized into separate frontend and server directories.

## Structure

- **frontend/**: Contains the React (TanStack Start) application.
- **server/**: Dedicated directory for backend/server-side code.

## Getting Started

### Frontend
To run the frontend:
```bash
cd frontend
npm install
npm run dev
```

### Server
The server directory is currently empty and ready for your backend implementation.
